## 上传文档

1. 打开本仓库的 `docs` 目录，点击 **Add file → Upload files**。
2. 上传 `.html` 或 `.htm` 文档。图片、CSS、JS 等资源请一起上传，并保持原有相对目录关系。
3. 点击 **Commit changes**，提交到 `main`。
4. 在 **Actions → pages build and deployment** 查看发布结果。成功后，知识库目录会自动更新，网站入口无需修改。

可按主题建子目录，例如 `docs/agent/入门.html` 和 `docs/agent/images/流程.png`。文档内使用 `images/流程.png` 等相对路径，避免 `/images/...` 根路径或本机文件路径。目录按照文件路径列出文档，保留 HTML 原始样式和交互。

本仓库及发布的文档公开可见。GitHub Pages 从 `main` 分支根目录发布，`index.html` 自动列出 `docs/` 下的 HTML 文件；不要把私人资料放入此仓库。

无需安装依赖或修改代码。目录使用 GitHub 公共 API，遇到网络问题或访问频率限制时，可通过页面上的 GitHub 文档目录查看文件。配套资源保持相对路径即可。根目录的 `index.html` 和 `.nojekyll` 为发布设施，不包含示例文章。
