常见面试题

Nginx的并发能力在同类型网页服务器中的表现，相对而言是比较好的，因此受到了很多企业的青睐，我国使用Nginx网站的知名用户包括腾讯、淘宝、百度、京东、新浪、网易等等。Nginx是网页服务器运维人员必备技能之一，下面为大家整理了一些比较常见的Nginx相关面试题，仅供参考：

1、请解释一下什么是Nginx?

Nginx 是一个高性能的HTTP和反向代理服务器，用于HTTP、HTTPS、SMTP、POP3和IMAP协议。

2、请列举Nginx的一些特性。

  1. Web服务器
  2. 反向代理
  3. 负载均衡
  4. 缓存
  5. SSL/TLS 终止
  6. 压缩
  7. 访问控制
  8. 日志记录

3、请解释Nginx如何处理HTTP请求。

Nginx使用反应器模式。主事件循环等待操作系统发出准备事件的信号，这样数据就可以从套接字读取，在该实例中读取到缓冲区并进行处理。单个线程可以提供数万个并发连接。

4、在Nginx中，如何阻止处理那些使用未定义服务器名称的请求?

可以通过配置一个默认的server块来实现。这个默认的server块会捕获所有未被其他server块匹配的请求，并返回一个错误响应或直接关闭连接。

在Nginx配置文件中，定义一个server块，并将其server_name设置为_（下划线），这是一个通配符，表示匹配所有未定义的服务器名称。

server {
    listen 80 default_server;
    server_name _;
    return 444;  # 关闭连接，不发送任何响应
}

server {
    listen 80;
    server_name example.com;

    location / {
        root /var/www/html;
        index index.html index.htm;
    }
}

5、 使用“反向代理服务器”的优点是什么?

反向代理服务器可以隐藏源服务器的存在和特征。它充当互联网云和web服务器之间的中间层。这对于安全方面来说是很好的，特别是当您使用web托管服务时。

6、请列举Nginx服务器的最佳用途。

Nginx服务器的最佳用法是在网络上部署动态HTTP内容，使用SCGI、WSGI应用程序服务器、用于脚本的FastCGI处理程序。它还可以作为负载均衡器。

7、请解释Nginx服务器上的Master和Worker进程分别是什么?

Master 进程是 Nginx 的主控制进程，负责管理和监控 Worker 进程。它的主要职责包括：

  • 启动和停止Worker进程
  • 配置文件管理：负责加载和解析Nginx配置文件（如nginx.conf）。
  • 信号处理：监听系统信号（如SIGHUP、SIGTERM等），并根据信号执行相应的操作。
  • 监控Worker进程
  • 特权操作：Master进程通常以超级用户（root）权限运行，以便执行需要特权的操作（如绑定到低于1024的端口）。

Worker进程是实际处理客户端请求的进程。每个Worker进程都是独立的，能够处理多个并发连接。它的主要职责包括：

  • 处理客户端请求：Worker进程负责接收、解析和处理客户端请求。
  • 事件驱动模型：Worker进程采用事件驱动（Event-Driven）和非阻塞I/O模型，能够高效处理大量并发连接。
  • 多核利用：通过配置多个Worker进程，Nginx可以充分利用多核CPU的性能。

Master进程和Worker进程的关系

  • 主从架构：Master进程是主进程，负责管理和监控Worker进程。Worker进程是从进程，负责实际处理请求。
  • 通信机制：Master进程和Worker进程之间通过信号和共享内存进行通信。Master进程可以向Worker进程发送信号（如SIGTERM），而Worker进程可以通过共享内存传递状态信息。
  • 高可用性：如果某个Worker进程崩溃，Master进程会立即重新启动一个新的Worker进程，确保服务的高可用性。

9、请解释是否有可能将Nginx的错误替换为502错误、503?

502 =错误网关

503 =服务器超载

有可能，但是您可以确保fastcgi_intercept_errors被设置为ON，并使用错误页面指令。

Location / {
fastcgi_pass 127.0.01:9001;
fastcgi_intercept_errors on;
error_page 502 =503/error_page.html;
#…
}

11、在Nginx中，解释如何在URL中保留双斜线?

要在URL中保留双斜线，就必须使用merge_slashes_off;

语法:merge_slashes [on/off]

默认值: merge_slashes on

环境: http，server

12、请解释ngx_http_upstream_module的作用是什么?

ngx_http_upstream_module用于定义可通过fastcgi传递、proxy传递、uwsgi传递、memcached传递和scgi传递指令来引用的服务器组。

13、请解释什么是C10K问题?

C10K问题（即“Concurrent 10,000 Connections”问题）是指如何设计一个网络服务器，使其能够同时处理10,000个并发连接。这个问题最早由Dan Kegel在1999年提出，当时互联网的快速发展使得传统的服务器架构无法有效应对大量并发连接的需求。

14、请陈述stub_status和sub_filter指令的作用是什么?

Stub_status指令：该指令用于了解Nginx当前状态的当前状态，如当前的活动连接，接受和处理当前读/写/等待连接的总数

Sub_filter指令：它用于搜索和替换响应中的内容，并快速修复陈旧的数据

15、解释Nginx是否支持将请求压缩到上游?

您可以使用Nginx模块gunzip将请求压缩到上游。gunzip模块是一个过滤器，它可以对不支持“gzip”编码方法的客户机或服务器使用“内容编码:gzip”来解压缩响应。

16、解释如何在Nginx中获得当前的时间?

要获得Nginx的当前时间，必须使用SSI模块、$date_gmt和$date_local的变量。

Proxy_set_header THE-TIME $date_gmt;

17、用Nginx服务器解释-s的目的是什么?

在Nginx中，-s 是一个命令行参数，用于向Nginx主进程（Master Process）发送信号，以控制Nginx的运行状态。-s 参数通常与以下子命令一起使用：

  • nginx -s stop：立即停止Nginx。
  • nginx -s quit：优雅地停止Nginx（等待处理完当前请求后停止）。
  • nginx -s reload：重新加载配置文件（无需重启Nginx）。
  • nginx -s reopen：重新打开日志文件。

18、解释如何在Nginx服务器上添加模块?

在编译过程中，必须选择Nginx模块，因为Nginx不支持模块的运行时间选择。
