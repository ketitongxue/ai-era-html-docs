CSS

CSS 进行版面设计和网页的美化

CSS 主要有三种方式来发挥它的作用

第一个方式是将语法直接写在 HTML 标签里面，但是每一个地方都要修改。

<h2 style="color:red">Document</h2>

第二个方式是把 CSS 语法统一写到 <head> 标签里面，并且前后用 style 标签包覆起来.

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        h2{
            color:red;
        }
        p{
            color:blue;
            font-size: 36px;
        }
    </style>
</head>

但由于一个网站是由多个网页组成的，如果要在每个网页个别嵌入 CSS 语法，这对于一个大型网站来说是个麻烦且不切实际的做法。

因此一个比较理想的方式是把 CSS 语法整个搬移出来，变成一个独立的样式表。

创建 style.css，然后要将这个样式表连回原来的 HTML 网页

h2{
    color:red;
}
p{
    color:blue;
    font-size: 36px;
}

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="stylesheet" href="css/style.css">
</head>

浏览器本身有内建 CSS 样式

padding：上 右 下 左

CSS 中重要的三个属性：

  1. border 边框
  2. padding 内边距
  3. margin 外边距，浏览器本身有内建CSS样式，有一些内设值

padding

四边

padding: 10px;

前一个值代表上下，第二个值代表左右

padding: 10px 20px;

前一个值代表上，第二个值代表左右，第三个值代表下

padding: 10px 20px 30px;

前一个值代表上，第二个值代表右，第三个值代表下，第四个值代表左

padding: 10px 20px 30px 40px;

重设 margin

* {
    padding: 0;
        margin: 0;
}
