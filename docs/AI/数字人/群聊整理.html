有 OpenAI 账号和 api key 当然最好。不过我们主要用开源 LLM Qwen3 和 DeepSeek-R1。

DeepSeek 据说在憋大招，可能 DeepSeek-R2 也快出来了，或者叫其他名字。我估计 DeepSeek-V3、DeepSeek-R1 会合并起来搞一个新的 LLM。

很多平台都部署了 DeepSeek-R1，我目前用阿里云百炼平台上的。因为百炼平台上还有 Qwen3 满血版。

qwen3 真的蛮好用的，小巧精致，8b 版就可以做很多事了，普通配置的机器跑起来完全没问题。支持 deepseek-r1 那样的 think 模式，还支持 function call、对 json 输出的支持也很好。

开源 LLM 方面，阿里巴巴就是世界领先，不用去满世界吹牛遥遥领先。

我没有仔细看过A2A，不过从概念上A2A和MCP根本不是一个层面上的东西。

MCP宇宙中的每个星球球内部国家的通信协议，A2A是宇宙中星球和星球的通信协议

地球🌏如何和月亮通信，可以用A2A定义好

MCP从概念上是和Assistants API一个层面的东西。解决的是 LLM 通过调用外部系统的功能来与现实世界中的各种数据和技能对接的问题。形象上说就是给 LLM 的大脑装上健壮的四肢，让 LLM 应用不仅可以对话，还可以完成复杂的任务。

这样界王神大人就可以更加方便的使用和管理星球

MCP 可以理解为更好的 Assistants API，有大量的应用场景。

A2A 则有些尴尬，应用场景有限。A2A 是与那个 Agent Protocol 同等级别的概念。
