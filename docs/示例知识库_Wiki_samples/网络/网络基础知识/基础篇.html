DNS、HTTP、HTTPS 所在的层是应用层，应用层封装后，浏览器会将应用层的包交给下一层去完成，通过socket 变成来实现。

下一层是传输层。传输层有两种协议，TCP 和 UDP。

传输层封装完毕后，浏览器会将包交给操作系统的网络层。网络层的协议是 IP 协议。在 IP 协议里会有源IP地址，即浏览器所在机器的 IP 地址和目标地址。

然后操作系统将 IP包交给下一层，也就是 MAC 层。网卡再将包发出去，由于这个包里面是有 MAC 地址的，因此能够到达网关。

路由协议常用的有 OSPF 和 BGP。

应用层 DHCP、HTTP、HTTPS、RTMP、P2P、DNS、GTP、RPC
传输层 UDP、TCP
网络层 ICMP、IP、OSPF、BGP、IPSec、GRE
链路层 ARP、VLAN、STP
物理层 网络跳线
